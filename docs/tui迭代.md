设计要点：

消息气泡：用户消息右对齐（或浅色背景块），AI 消息左对齐，用颜色 + 前缀 You / AI 区分，无头像。

流式渲染：新 token 到达时即时重绘。

多行输入：长问题动态增加输入框大小。

顶部会话：显示会话标题（默认为首条消息截断）。

可读性：消息间留空行，AI 消息可包含 Markdown 粗体/代码高亮（基于 ratatui 的 Span 样式）。

配色方案：基于 Tokyo Night 或 Nord 主题，柔和护眼，强调色用于区分角色。
